| Concept | The course required seven-class grayscale expression classification and an independent final evaluation. The early plan separated data/model work from later interactive presentation. | Defined a data contract and a baseline before making product decisions. [Requirements](REQUIREMENTS.md) |
| T1 · Data foundation | Inspect fields, counts, label ordering and tensor shape; establish split-aware loaders and tests. | A Training/PublicTest pipeline made the baseline possible. [Loader](../src/dataset.py) |
| T2 · BasicCNN | Use a short smoke run to validate the path, then a 15-epoch Adam baseline with full allowed splits. | 1,947/3,589 on PublicTest (54.249094%). Saved curves and reload evidence motivated improvements. [T2 record](../results/t2_baseline_20261030/) |
| T3 · Residual transition | Compare continued CNN training, geometric augmentation, MPS, BN, residual blocks, and weighting. Use the epoch-50 residual parent for short controlled fine-tunes. | Seed-42 unweighted e56 reached 2,453/3,589. Class weighting gave mixed effects. Fixed-state CE worsened despite improved accuracy. [Comparison](EXPERIMENTS.md) |
| T3.5–T3.6 · Diagnosis and research | Examine overconfidence, duplicate images and class confusion. Test cosine scheduling, label smoothing, EMA with BN refresh and photometric augmentation. Review alternatives before wider runs. | C EMA seed 42 improved by five cases, with paired uncertainty crossing zero. The historical T3 checkpoint remained selected. Research did not supply project performance claims. [Decisions](EXPERIMENTS.md) |
| T3.7 · Width and training recovery | Compare w16/w32 with warmup/cosine SGD. Record interruption, partial runs and resume checks separately. | Both seed-101 runs finished 100 epochs. w32 raw 2,511/3,589, w16 raw 2,459/3,589. Seeds 202 and 303 have no complete comparisons. [Configs](../configs/t37/) |
| T3.8 · Inference experiments | Compare raw w32, per-model flip TTA, two-model and three-model probability means, and a four-view alternative. | The three-model two-view path reached 2,606/3,589. Four views lost nine correct against it. [Frozen evidence](../results/t38_triple_tta_20261104/run01/summary.json) |
| T4 · Analysis and CLI | Recheck course requirements, build comparative curves, matrices and paired error counts. Consolidate one CPU ensemble entry point. | Verified reload and Mac CLI, with 22 original chart subjects and a common inference path for later web adapters. [Ledger](../experiments/README.md) |
| T5.1–T5.4 · HUMAN SIGNAL | Move from only pre-cropped gray inputs to YuNet detection and explicit crop confirmation. Add ImageIO for hard formats and sampled LIVE with frame timing and status. | PHOTO and LIVE use the same classifier. Raw and smoothed readouts become visible; the system handles lost tracks and releases the camera. [Product](PRODUCT_DESIGN.md) |
| T6.1–T6.3 · Seven Signals and freeze | Design seven geometry/motion scripts, integrate them into PHOTO/LIVE, add independent frame capture and inference, then refine movement and layout. | Shared class-to-art mapping and a standalone gallery. FROZEN FRAME exposes a separate prediction of the captured image. [Seven Signals](SEVEN_SIGNALS.md) |
| T7.1–T7.3 · Expression Challenge | Turn stable raw-frame matching into a timed task with explicit failure states, replay and scoring. | T7.2 controlled full game reached 200/700. T7.3 controlled long run recorded 11 games and 77 rounds. Physical-device evidence remains scope-specific. [Game](GAME_DESIGN.md) |
| T8.1–T8.4 · Acceptance | Unify launch at port 8797, fix PHOTO disconnect handling, validate loopback requests, resource recovery and classroom charts. | T8.4 local engineering closeout reused T8.3 Chrome physical-camera evidence and marked Safari controlled-only coverage. [Validation](TESTING_AND_VALIDATION.md) |
| T9.1–T9.2.1 · Freeze and preflight | Fix three checkpoint identities, input, weights and CPU procedure. Examine held-out isolation and tighten local data controls. | Synthetic and historical aggregate checks passed. Formal holdout evaluation remained unexecuted under the course procedure. [Inference](ENSEMBLE_INFERENCE.md) |
| T9.3–T9.4 · Report and defense | Build the formal report, original chart annex, four preparation tracks and 22-slide defense materials. | Local deliverables exist. Individual claims and eventual classroom approval need their own evidence. [Team](TEAM_AND_CONTRIBUTIONS.md) |
| T10 · Archive and confirmation | Organize teacher and team sources, four presentation tracks and the source-to-evidence map; repeat non-held-out regressions. | 26 Python inference checks, 43 frontend and sculpture checks, six weight/config hashes and historical count arithmetic. [Validation](TESTING_AND_VALIDATION.md) |
