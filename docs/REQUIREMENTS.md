# Course requirements and project scope

The two-page written notice assigns a Python-based seven-class facial expression project. It suggests PyTorch and requires data checks and preprocessing, actual training, loss and accuracy records, a separated final evaluation, readable code, and individual explanations. The input is a 48 × 48 grayscale face. The grading weights are 30% for model performance, 20% for code quality, 40% for individual understanding and 10% for collaboration. The notice schedules in-class acceptance for 2026-12-01. Acceptance has yet to be documented.

| Dataset role | Records | Purpose |
| --- | ---: | --- |
| Training | 28,709 | Parameter updates |
| PublicTest | 3,589 | Validation, tuning and model selection |
| PrivateTest | 3,589 | Independent final evaluation under course procedure |

The team added HUMAN SIGNAL to make the inference process observable. Automatic PHOTO preparation, LIVE feedback, FROZEN FRAME, Seven Signals and Expression Challenge have separate engineering evidence. The course metrics use already cropped inputs.
