| 最初构思 | 教师书面要求 48×48 灰度七类分类、真实训练和独立测试。早期策划先建立数据与基础模型，再接产品演示。 | 先确定可追溯的数据契约和基线。[课程要求](REQUIREMENTS.md) |

| T3 残差路线 | 依次试继续训练、增强、MPS、BN、小图残差和类别加权，基于第 50 轮残差父权重微调。 | 无加权 seed42 第 56 轮为 2453/3589。加权在不同种子上的方向不一致，验证 CE 后期上升。[实验](EXPERIMENTS.md) |
| T3.5–T3.6 诊断和研究 | 检查过拟合、过度自信、相同像素与标签冲突，并做余弦微调、标签平滑、EMA/BN 重估及轻度光度增强。调研下一步容量方向。 | C 正式流 seed42 净增 5 张，成对区间跨 0，原 T3 继续作为正式权重。论文指标只作为方向参考。[实验](EXPERIMENTS.md) |
| T3.7 宽度对照 | 在记录启动中断与分段恢复的基础上，尝试 w16/w32、预热加余弦 SGD。 | seed101 两宽度各完成 100 轮，w16 原图 2459/3589，w32 原图 2511/3589。seed202/303 没有完整对照。[配置](../configs/t37/) |
| T3.8 推理对照 | 比较单模型原图和翻转、双模型、三模型以及四视图方案。 | 三模型双视图 2606/3589，四视图净少 9 张。[原摘要](../results/t38_triple_tta_20261104/run01/summary.json) |
| T4 分析和统一推理 | 重查教师依据，整理真实曲线、混淆及配对误差，做 Mac 重载验收并统一 CPU CLI。 | 固定分类入口供后续产品调用，形成 22 个图表主题。[实验索引](../experiments/README.md) |
| T5.1–T5.4 照片和实时 | 从严格小图扩展到普通照片、YuNet 定位与裁剪确认，再加入 ImageIO 兼容及摄像头采样。 | PHOTO 和 LIVE 共用分类器。RAW、平滑显示和异常状态可分别观察。[产品](PRODUCT_DESIGN.md) |
| T6.1–T6.3 数字艺术和定格 | 七类带面从独立预览进入 PHOTO/LIVE，加入单帧抓取独立推理，精修动效和版式。 | 类别映射统一，还能单独浏览七件作品。实时平滑和定格结果可分别查看。[七件雕塑](SEVEN_SIGNALS.md) |
| T7.1–T7.3 表情挑战 | 为实时原始帧增加目标、计时、稳定匹配、暂停、重试与局结算。 | T7.2 受控七轮记录 200/700，T7.3 受控连续 11 局、77 回合。真人覆盖按实际版本记录。[游戏](GAME_DESIGN.md) |
| T8.1–T8.4 工程验收 | 统一 8797 入口，完善断连恢复、资源检查、离线进程和四张课堂图表。 | 本机工程结项，复用 T8.3 Chrome 真人证据。Safari 真人与教室实体设备待验证。[验收](TESTING_AND_VALIDATION.md) |
| T9.1–T9.2.1 冻结和预检 | 固定权重、输入和 CPU 推理规则，核对评估器与保留集隔离。 | 合成验证与既有历史证据通过，正式独立评估待教师流程确认。[冻结](ENSEMBLE_INFERENCE.md) |
| T9.3–T9.4 报告和答辩 | 整理正式实验报告、图表、四人中文复习材料与 22 页答辩稿。 | 已有本地成品。个人实际贡献和正式课堂验收需单独确认。[分工](TEAM_AND_CONTRIBUTIONS.md) |
| T10 完整归档 | 整理教师材料、个人专题与组会议程，跑指定非保留集回归。 | 冻结推理 26 项、前端及雕塑 43 项，权重和配置 6 项摘要核对通过，历史计数复算一致。[验证](TESTING_AND_VALIDATION.md) |
