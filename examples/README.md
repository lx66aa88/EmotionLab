# Example inputs

Run `python examples/make_smoke_image.py smoke-48.png` to create a 48 × 48 grayscale pattern for CLI and tensor smoke tests. The pattern has no face or ground-truth class. Any output shows that the prediction path runs.

For PHOTO or camera testing, use an image or camera feed that you have permission to process. Course dataset rows and derived sample images are distributed separately, if authorized.
